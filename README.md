# experiments

Small, self-contained ML experiments. Each directory is its own project with its own README and
dependencies.

| Project | What it is |
|---|---|
| [simple-llm-train](simple-llm-train/) | Char-level transformer LM: dataclass config with profiles, W&B, checkpoints with resume, TinyStories/TinyShakespeare corpora |
| [claude-plugin-eval-raw-trail](claude-plugin-eval-raw-trail/) | First run of `claude plugin eval`: a 7-case with/without ablation suite for the gh-cli plugin, plus the recorded run (mean delta +0.56) |
